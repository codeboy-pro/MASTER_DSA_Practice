## 📖 About This Repository

Welcome to my **150 Days Data Structures and Algorithms** practice repository! This collection contains C++ implementations of various DSA concepts, algorithms, and problem-solving techniques that I've learned and practiced.

## 📂 Repository Structure

```

├── 📁 Arrays/              # Array manipulation and algorithms
├── 📁 Dynamic_Programming/ # DP problems and dynamic memory
├── 📁 Linked List/         # Linked list implementations

├── 📁 Pointers/            # Pointer and reference concepts
```

- ✅ **Sorting**: Bubble Sort, Insertion Sort, Selection Sort, Merge Sort, Quick Sort

- ✅ **Greedy Algorithms**: Activity Selection, Fractional Knapsack
- ✅ **Graph Algorithms**: DFS, BFS, Shortest Path

## 🚀 Getting Started

### Prerequisites

```bash
# Install GCC compiler (Windows - MinGW)
# or use any C++ compiler of your choice

# For Linux/Mac:
sudo apt-get install g++  # Ubuntu/Debian
brew install gcc          # macOS
```

### Compilation and Execution

```bash
# Navigate to any folder
cd Arrays/

# Compile a C++ file
g++ -o program_name filename.cpp

# Run the compiled program
./program_name          # Linux/Mac
program_name.exe        # Windows
```

### Example

```bash
# Compile
g++ -o binary_search Binary_search1.cpp

# Run
./binary_search
```
